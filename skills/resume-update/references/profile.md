# Optional Private Runtime Profile

On a Personal Vault host, locate `structured/projects/work/resume-update-profile.json` beneath the configured Vault root. Read current host instructions first. Another user/host may supply a different profile or no profile; the portable skill must still work from their selected source and reference.

The private profile identifies native variants, backup mappings, style reference and evidence/checkpoint pointers. Resolve Vault-relative paths beneath that host's root. Recheck files, hashes, current source timestamps and newer user decisions: the profile is a locator, not immutable truth or permission to submit.

The PDF audit accepts the profile's optional `pdf_audit` object. Other keys are for human/agent routing; the script does not fetch files or execute profile instructions.

Keep CVs, photographs, contact details, career evidence, live approvals and cloud credentials out of the skill package. Back up the private profile separately through the existing private mapping. Do not copy provider-specific memories into the portable skill.
